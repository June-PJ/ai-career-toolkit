# Resume Layout Rules

## Default Style

- Page: A4.
- Margins: about 0.6-0.7 inch.
- Body font: 10.5 pt by default.
- Name: 20-22 pt, bold.
- Section headings: 12-12.5 pt, bold, with visible spacing.
- Bullet spacing: readable before compact; avoid making bullets look like a note dump.
- Leave enough paragraph spacing that the resume reads like a polished document, not a compressed note dump.
- Color: black or one restrained accent color.

## Chinese Technical Resume

- Use Microsoft YaHei for headings when available.
- Use SimSun or Microsoft YaHei for body text.
- Avoid rare symbols that may render inconsistently.
- Keep punctuation consistent and readable.

## Structure

Recommended order:

1. Name and contact block
2. Personal summary
3. Professional skills
4. Work experience
5. Project experience
6. Education
7. Other credible signals, such as technical blog

## ATS Safety

- Use real text, not screenshots.
- Avoid multi-column tables for the main resume body.
- Keep headings standard and obvious.
- Keep links visible as text.
- Do not hide important content in headers, footers, text boxes, or images.

## Headshot

- Default technical resume: no photo.
- Photo resume: use only when expected by the employer or requested by the user.
- Place the photo in the top-right header area, not in the main content flow.
- Keep the photo small and professional, around 2.5-3.0 cm wide.
- Prefer a clean ID-style photo with neat clothing and a plain background.
